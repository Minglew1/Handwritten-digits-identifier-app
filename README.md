# Handwritten-digits-identifier-app
This repo builds a 4 layer neural network from scratch to recognise handwritten digits. Project based mainly on python library torch. 
It has a small GUI to draw and test the neural network

# Running the code

```python main.py```

The trained model will be stored in ```mnist_model.pth```, remove it and then run the code if you want to create a new model

# The GUI
When the GUI appears, draw in the canvas for the neural network to make its prediction. Press ```R``` to delete the drawing.
The prediction appears on the bottom left of the GUI, and on the bottom right appears the compressed version on which the neural network makes its prediction
